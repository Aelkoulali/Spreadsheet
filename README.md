# 🗂️ Spreadsheet 📄 
This Spreadsheet project is a web-based mini application built using JavaScript, HTML, and CSS. It uses a functional programming approach by breaking the logic into smaller, reusable functions and combining them to perform features like searching, filtering, and displaying data.

The project relies on key JavaScript tools: parseInt() to convert input values into numbers, map() to transform arrays (for example, generating updated rows/cells), find() to locate a specific item in a dataset, and includes() to check whether a value exists (commonly used for search or validation).

Overall, it demonstrates how functional programming concepts can make code cleaner, modular, and easier to manage while building spreadsheet-like behavior in the browser.


## ✅ Key Features
- Event handling (click to roll)
- Random dice roll using JavaScript
- Conditional logic for game result (win/lose/draw — add your rules)
- User interface updates (show dice + score)

## 🛠️ Tech Stack
- HTML
- CSS
- JavaScript: 
   - Functional programming with map(), find(), includes()
   - Number parsing with parseInt()

 

## ▶️ How to Run
Open `index.html` in your browser.
